# 实现约定

个人本地应用，Node.js 标准库 HTTP 服务，前端使用原生 ES 模块，数据存入 data/store.json 并原子替换。仅监听 127.0.0.1。

任务保留计划日期；当日期早于今天且未完成时，在今日列表展示为顺延。完成时间决定成果归属。打卡按每日独立记录。同一周以周一日期标识，跨月周归属周一所在月份。统计仅计算选定期间，任务完成率以计划日期归属计算。

节点：1. 基础服务与数据模型；2. 记录、分类和成果；3. 统计、分层复盘与 Markdown 导出；4. 验证与使用说明。

参考：https://github.com/cockpit-project/cockpit 。借鉴模块化 Web 工作区，不依赖 Cockpit 的 Linux 管理服务。
